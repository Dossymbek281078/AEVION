# QReal Studio — спецификация модуля

> Создано 2026-07-21. Worktree `aevion-qreal`, ветка `feat/qreal-studio-mvp`.
> Отдельно от DevHub (по решению основателя). Страница `/qreal`, API `/api/qreal/*`.

## 1. Видение

Приложение, где по текстовому брифу рождается **полностью живое видео** — люди,
дети, животные, птицы, лес, трава, ветер, дождь, голоса и звуки — неотличимое от
съёмки. Ключевой обход: **не нужен актёр и не нужно референс-видео себя** —
сегодняшний стандарт «сними себя, потом оживим» убирается полностью.

## 2. Честная оценка (правило объективности)

**Что НЕ работает как путь:**

1. **«Возьмём огромный срез видео людей и детей из интернета и обучим свою
   модель».** Обучение видео-foundation-модели уровня Veo 3 / Sora 2 — это
   $50–300M compute (десятки тысяч H100 на месяцы), петабайтный дата-пайплайн и
   команда research-инженеров. Для соло-основателя это не «сложно», это
   невозможно на 3+ порядка бюджета. *(Оценка по публичным данным об обучении
   Sora/Veo-класса; гипотеза в деталях, порядок величин — надёжный.)*
2. **«Открытые данные» с людьми и детьми — юридически не открытые.** Видео в
   интернете ≠ разрешение обучаться: право на образ, GDPR (биометрия),
   ToS платформ. Скрейпинг видео **детей** — отдельная красная зона, которая
   похоронит и модуль, и репутацию планеты. AEVION сам строит IP-бюро на
   провенансе — строить генератор на серых данных значит противоречить
   собственному продукту.
3. **Неотличимость без маркировки не продаётся легально**: EU AI Act art. 50
   требует раскрытия синтетики. Поэтому маркировка в QReal неотключаемая —
   и это конкурентное **преимущество** (доверие, B2B, реклама, кино).

**Что РАБОТАЕТ как путь (и где Higgsfield «плавает»):**

Реалистичность сегодня проигрывается не в базовой модели, а в **режиссуре и
контроле качества**. Одиночный prompt → «пластиковый» кадр. Наш разрыв:

- **Пайплайн вместо промта**: бриф → AI-раскадровка → render-промты с вшитыми
  директивами реализма (микромимика, моргание, SSS кожи, руки, физика ткани,
  room tone, фоли, 24fps/180°) → лучший движок под задачу.
- **QC-петля реализма — ядро IP**: VLM-судья скорит каждый рендер по 14
  взвешенным критериям; кадр ниже порога перегенерируется автоматически.
  Ни один массовый генератор так не делает — юзер сам жмёт reroll.
- **Fine-tune позже и только на чистых данных**: LoRA/пост-тюн на лицензионном
  футадже (CC0, купленный сток, свои съёмки) под ниши — казахские лица, степь,
  этология конкретных животных. Это тысячи долларов, не миллионы, и легально.

## 3. Архитектура (реализовано в MVP)

```
aevion-globus-backend/src/routes/qreal.ts   ← роутер (in-memory, как qskyway)
  бриф → guardrail (реальные люди только с согласием)
       → раскадровка (LLM через qcoreai providers, fallback: детерминированная)
       → render-промт = сцена + REALISM_DIRECTIVES
       → engines registry (higgsfield/elevenlabs/ffmpeg, честные configured-флаги)
       → QC: 14 критериев (веса; runs/pending до подключения движка)
       → provenance: C2PA-style манифест, sha256, aiGenerated=true (всегда)
moduleManifest.ts                            ← mount /api/qreal (append-only)
frontend/src/app/qreal/                      ← светлый газетный UI (глобальный эталон)
```

Демо-проект «Утро в степи» засеян: 4 кадра (степь / мальчик+собака /
бабушка / беркут) — витрина живая без логина и без ключей.

## 5. Правовые рельсы (вшиты в код)

- `depictsRealPeople=true` без `consentConfirmed=true` → 422.
- Провенанс-манифест генерируется всегда, тумблера нет.
- Обучение только на лицензионных/собственных данных (P6), не на скрейпе.
