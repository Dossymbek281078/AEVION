# 🔴 Задача дня идёт из запасного пула — ворота 5 не пройдены

Нашлось при проверке «ради чего человек вернётся завтра». Замер по живому
проду 19.08, каждая строка — отдельный запрос:

| Запрос | Ответ |
|---|---|
| `/api/cyberchess-daily/puzzle` | 200, `poolSize: 30`, `source: "…fallback pool — the live daily puzzle is /api/cyberchess-puzzles/daily"` |
| `/api/cyberchess-puzzles/daily` | **404**, «Cannot GET» |
| `/api/cyberchess-puzzles/meta` | `bankTotal: 502584` |

Маршрута `"/daily"` нет ни в `deploy/chess-live-2026-08-19`, ни в
`frontend-all`, ни у меня — у пазлов только `/`, `/themes`, `/meta`,
`/reload`. То есть ссылка в подписи ведёт на ручку, которой не существует.

**Что это значит для 30 августа.** В банке полмиллиона задач, а ежедневная
крутится по кругу из тридцати: у вернувшегося через месяц человека пойдут
повторы. Задача дня — единственная причина возвращаться назавтра, то есть это
прямо ворота 5 доски запуска.

**Почему это вообще заметно.** Только потому, что подстановка честно помечена
в самих данных (`source`), а не подставлена молча. Это сделано правильно —
благодаря метке дефект виден снаружи одним запросом.

**Не чиню сам:** `cyberchessPuzzles.ts` у вас в активной правке (2 коммита в
ветке выкатки), лезть туда — гарантированный конфликт. Нужен маршрут `/daily`,
который выбирает задачу из основного банка детерминированно по дате (чтобы у
всех в один день была одна и та же), и тогда запасной пул останется тем, чем
должен быть, — запасным.

Со своей стороны поправил сводку готовности: она читала `poolSize` и отвечала
«да, честно», теперь читает метку `source` и краснеет.
