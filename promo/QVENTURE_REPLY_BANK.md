## 1. "Survivorship bias — you only tested winners."
The single most likely objection. Concede it head-on:
> Totally fair — three known winners is not a validation set, it's an illustration. The point I found interesting is the opposite of survivorship: even on the winners, with only seed-stage info, it said WATCH, not INVEST — because the risks were genuinely real then. I'm about to run the graveyard too (WeWork, Quibi, Juicero); if it doesn't flag those harder, the weights are wrong and I want to know.

## 2. "How are the 8 factors weighted? Why those weights?"
> Every factor shows its weight and rationale in the output, so you can argue with each one. Rough starting rubric: market ~0.18, moat ~0.16, unit economics ~0.14, execution ~0.14, timing ~0.12, then science/tech, legal, competition. They're a defensible default, not gospel — which factor would you reweight for a pre-traction marketplace, and why? That's exactly the feedback I want.

## 3. "This is just an LLM wrapper / a vibe with extra steps."
> The score isn't an LLM — it's deterministic code over a sector knowledge base, so the same input always returns the same number and every point is auditable. Only the 4-role council narrative uses a model, and it degrades to a deterministic template with no key. I built it precisely because the "AI for VCs" tools that give you an un-interrogatable number annoyed me.

## 4. "Who's it for / what's the business model?"
> Angels, micro-VCs, solo GPs, scouts, and syndicates who want a repeatable rubric instead of gut feel. Free tier to try, paid for saved reports/compare/PDF export. It's a screening aid to make judgment faster and more transparent — explicitly not investment advice.

## 5. "Isn't this basically giving investment advice?"
> No — and that line matters to me. It's a screening/diligence aid: a transparent score + a memo you can defend in an IC meeting. It doesn't tell you to buy anything, and every report carries that disclaimer. The human still decides.

## 6. "Has it been validated against actual outcomes?"
> Honestly, no — it's a rubric, not a predictor, and I won't pretend the backtest is proof. What I'd love to build next is a real outcome dataset (scored-at-seed vs. what happened) so the weights can be calibrated against reality instead of my priors. If you'd contribute anonymized picks, I'm in.

## 7. "WATCH on all three = the model is useless / hedging."
> It gives INVEST and PASS too — these three were genuinely borderline at seed, which is the honest read. Run a hype-cycle darling with thin unit economics and you'll get a PASS with reasons; run something with proven traction and clean margins and it'll say INVEST. WATCH here specifically means "enter small, stage in," and it sizes that for you.

## 8. "Can it handle [my sector / my geography]?"
> 18 sectors (fintech, healthtech, biotech, climate, AI infra/app, SaaS, marketplaces, deep tech, etc.) and any geography — you set the market. Easiest is to paste your own deal into the no-signup demo and tell me where it's wrong: https://aevion.vercel.app/qventure

## 9. "Where does the market data come from?"
> A curated 18-sector knowledge base with cited market-size sources (publisher + year shown in the report). It's not scraping live web by default — deliberately, so the score stays reproducible. You can see the citations under each analysis.

## 10. Generic "cool, nice work" / positive
> Thanks — if you run diligence, I'd genuinely value one line on which of the 8 factors you'd weight differently. That's the feedback that improves it. Demo's free, no signup: https://aevion.vercel.app/qventure
